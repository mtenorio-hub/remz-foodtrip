# Remz Foodtrip — Sample Marketing Website

A responsive, pink-themed static website featuring all 12 menu images from the provided menu ZIP, plus a searchable item-by-item menu with category filters and listed prices.

## Preview locally
Open `index.html` in a browser. Internet access is only needed for the optional Google Fonts.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `remz-foodtrip`.
2. Upload **all contents** of this folder (the `index.html`, `assets` folder, and `README.md`) to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will show your website URL in the Pages section, usually `https://YOUR-USERNAME.github.io/remz-foodtrip/`.

## Before publishing
- Replace the sample Facebook link in `index.html` (`https://www.facebook.com/`) with your actual Remz Foodtrip page or Messenger link.
- Add your shop location, opening hours, delivery/pickup details, and contact number if you want them displayed.
- Review the menu images and prices to make sure they are still current.

This is a static marketing site; it does not process payments or submit orders. The order button currently opens Facebook as a placeholder.
